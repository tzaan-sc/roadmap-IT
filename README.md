## Hướng dẫn

1. Học theo thứ tự từ trên xuống.
2. Mỗi level nên có 1 file note hoặc nhiều file theo từng chủ đề.
3. Khi học xong mỗi level, bạn có thể tạo thêm file như:
   - notes.md
   - roadmap.md
   - project.md
   - resources.md

## Mục tiêu

Học theo từng tầng kiến thức, không học lan man, để sau này có nền tảng vững và dễ đi sâu hơn vào một hướng cụ thể như Backend, Frontend, DevOps, Data, AI.
