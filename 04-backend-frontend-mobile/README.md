# Level 4 — Backend / Frontend / Mobile (Giai Đoạn Chuyên Môn Hóa)

> *"Biết rộng giúp bạn hợp tác tốt với đồng đội, nhưng một chuyên môn sâu sắc mới là thứ giúp bạn có mức thu nhập cao và không thể bị thay thế."*

Chào mừng bạn đến với **Level 4** trong lộ trình [Roadmap IT](../README.md). Sau khi đã hoàn thành nền tảng lập trình (Level 1), công cụ hệ thống (Level 2) và kiến thức phát triển Web cơ bản (Level 3), đây là thời điểm mang tính bước ngoặt: **Chọn đúng 1 hướng đi mũi nhọn và đào sâu để trở thành Kỹ sư chữ T (T-Shaped Engineer)**.

## 📚 Danh Sách Các Bài Học Chi Tiết

Dưới đây là 5 chuyên đề chuyên sâu đã được biên soạn hoàn chỉnh trong thư mục này:

| STT | Tên bài học | Nội dung trọng tâm | Đường dẫn |
| :---: | :--- | :--- | :---: |
| **01** | **Chuyên Sâu Kỹ Sư Backend** | 4 Trụ cột Kỹ sư Backend (Scalability, Reliability, Security, Maintainability), So sánh sâu bộ ba Framework chuẩn Enterprise: **NestJS** (Dependency Injection), **FastAPI** (Async & Pydantic), **Spring Boot** (Microservices & Security), Tối ưu Caching với Redis (Cache-Aside Pattern), Hàng đợi tin nhắn ngầm (RabbitMQ/BullMQ), So sánh REST vs GraphQL vs gRPC. | [Xem bài viết](./01-backend-specialization.md) |
| **02** | **Chuyên Sâu Kỹ Sư Frontend** | Cuộc cách mạng từ React SPA sang Next.js Fullstack, Phân biệt tường tận 4 cơ chế Rendering: **CSR, SSR, SSG, ISR**, Làm chủ **React Server Components (RSC)** và App Router, Quản lý State phân tách: Client State (**Zustand**) vs Server State (**TanStack Query**), Tối ưu bộ ba chỉ số **Google Core Web Vitals (LCP, INP, CLS)**. | [Xem bài viết](./02-frontend-specialization.md) |
| **03** | **Chuyên Sâu Kỹ Sư Mobile** | Sự khác biệt cốt lõi giữa Web và Mobile, Cuộc chiến giữa **Native** (Kotlin/Swift) và **Cross-Platform** (React Native/Flutter), Giải phẫu kiến trúc New Architecture của React Native (JSI, Fabric, TurboModules), Thiết kế ứng dụng theo mô hình **Offline-First**, Cơ chế thông báo đẩy (FCM/APNs), Quy trình Code Signing và phát hành Store. | [Xem bài viết](./03-mobile-specialization.md) |
| **04** | **Chiến Lược Chọn 1 Stack Chính** | Triết lý Kỹ sư chữ T (T-Shaped Engineer), Phân tích thị trường tuyển dụng và mức lương tại VN & Quốc tế, **4 Combo Stack Vàng** được săn đón nhất (Fullstack TypeScript, Python AI-Backend, Java Enterprise, Mobile Champion), Kế hoạch hành động 90 ngày bứt phá từ người học thành ứng viên sáng giá. | [Xem bài viết](./04-choosing-your-primary-stack.md) |

## 🎯 Mục Tiêu Đạt Được Sau Khi Hoàn Thành Level 4

1. **Xác định rõ ràng định hướng sự nghiệp:** Không còn hoang mang đứng núi này trông núi nọ, kiên định với 1 Stack công nghệ mũi nhọn.
2. **Nắm vững tư duy cấp độ Senior:** Hiểu tại sao các công ty lớn sử dụng Caching, Message Queue, Server-Side Rendering hay kiến trúc Offline-First thay vì chỉ viết code thông thường.
3. **Có ít nhất một Đồ án Portfolio "đinh" chất lượng cao:** Sẵn sàng đưa link GitHub và Demo sống vào CV để chinh phục các nhà tuyển dụng khó tính nhất.
4. **Tự tin bước vào phòng phỏng vấn:** Nắm vững câu trả lời chuẩn xác cho các câu hỏi kỹ thuật chuyên sâu hay gặp nhất của từng nhánh nghề nghiệp.
